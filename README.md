## Meaning and limits

This is a useful failure artifact: it demonstrates why shaping-layer output cannot be promoted directly to PDF semantic correctness. The fixture is untagged, generated by a renderer path that does not establish complex-script PDF conformance, and has no PDF/UA, ToUnicode, screen-reader, keyboard, or production proof. The next required experiment is a tagged PDF produced by a shaping-aware export path, followed by independent parser, raster, and validator checks.
