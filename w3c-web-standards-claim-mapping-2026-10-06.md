# W3C web-standard claim mapping — 2026-10-06

This receipt maps the accessible web-standard portions of C-008, C-009, and C-010. It does not provide ISO PDF 2.0, PDF/UA-2, PDF/A-4, or PDF/X-6 clause evidence.

## C-008 — CSS Paged Media Level 3

Official source: https://www.w3.org/TR/css-page-3/ (W3C Working Draft, 2023-09-14).

- Section 3 defines page boxes as finite rectangular surfaces for paged media.
- Section 4.1 defines the @page rule and page context.
- Section 7.1 defines the size property for page-box size and orientation.
- Section 5 covers page-margin boxes used for headers and footers.

## C-009 — CSS Fragmentation Level 3

Official source: https://www.w3.org/TR/css-break-3/ (W3C Candidate Recommendation, 2018-12-04).

- Section 3.1 covers break-before, break-after, and break-inside behavior.
- Section 3.3 defines widows and orphans constraints.
- Section 4.5 states that CSS does not define one required choice among allowed break points and gives optimization guidelines.

## C-010 — WCAG 2.2 text spacing

Official source: https://www.w3.org/WAI/WCAG22/UNDERSTANDING/text-spacing.html.

The page records SC 1.4.12 thresholds: line height 1.5 times font size, paragraph spacing 2 times font size, letter spacing 0.12 times font size, and word spacing 0.16 times font size, with a language/script exception.

These mappings support limited web-standard teaching claims only. They preserve Working Draft/Candidate Recommendation status and the web-versus-PDF boundary. The ISO normative-text, PDF/X-6 preflight, and human accessibility vetoes remain open.
